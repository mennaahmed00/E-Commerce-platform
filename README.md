## How to Run

1. **Clone the repository:**
   ```bash
   git clone <REPOSITORY_LINK>

```

2. **Navigate to the project directory:**
```bash
cd AI_work/AI_Agent

```


3. **Install dependencies:**
Install the required packages from `requirements.txt` on your machine (preferably inside a virtual environment):
```bash
pip install -r requirements.txt

```


4. **Activate virtual environment (if using one):**
```cmd
venv\Scripts\activate.bat

```


5. **Configure environment variables:**
In the `.env.example` file (or a new `.env` file), add your Gemini API key:
```env
GEMINI_API_KEY=your_gemini_api_key_here

```


6. **Run the application:**
```bash
python main.py

```
