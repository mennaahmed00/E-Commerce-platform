
How to run the file?
1- git clone <REPOSITORY_LINK>
2- cd AI_work
3-cd AI_Agent
4-install the dependencies in requirments.txt on your machine or prefferably in a virtual environment.
5-if you have created a virtual environment activate it using this command venv\Scripts\activate.bat
6-in the file .env.example add a GEMINI_API_KEY

then finally:
python main.py
